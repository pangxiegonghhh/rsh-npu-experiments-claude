## 2. 新发现（事后，本审核核算）

- **按行单价**：热档每补齐行 23.1–23.9 ns，跨两图、B0/B1、FP16/32、N128/256 都稳定（Cora FP16/N128 例外）。字节翻倍单价不变 → 在 N≤256 范围，代价跟条数走、不跟字节走，与 Ascend-SpMM 的 αN 模型不同。
- **ND 拆项**：用 B0/B1 两点解 `时间 = b×调用 + c×T`，得 b≈67–68 ns/调用、c≈134–142 ns/块，Cora 与 arxiv 一致（arxiv FP32/N256 略偏）。分界约 4.6 补齐行/调用。
- **热档 ND 偏低是两图共有的**：热档都比 API 预测低 5.9%–7.4%；arxiv 冷档反而高 6.5%–10.7%（B0 更碎，局部性更差）。
- **arxiv 上按行全胜**：B1 快 1.66–2.11 倍，B0 快 2.28–3.63 倍。
- **双峰**：B2′ 的 FP16/N128 按行有 8 个区组在低档、12 个在高档，差约 5%，同一区组内 8 个用例同档 → 启动级状态；配对比值安全，绝对值不安全。固定R项同格无双峰。
