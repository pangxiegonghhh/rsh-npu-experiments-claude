# 第5层 · 供数

**定了什么：**

- **A**：DataCopy 进 L1 → LoadDataWithTranspose → Mmad【定】。
- **B**：按第 2 层给窗口打的标记，走按行（每个补齐行一次 DataCopy）或 ND2NZ（每次调用搬一段或多段等长、等间距的段）。

**代办：**

- L5-1：B 的段合并规则。用户提供后放进 `段合并规则/`，规划方核对并按它复算调用次数。
- L5-2：写作约束，三条路径的 L1 布局只能写「最终输出逐位相同 + 共用同一条转置加载」。

两条路径混用（L2-4）、AIV 取 B（L2-5）按用户决定放在第 2 层。
