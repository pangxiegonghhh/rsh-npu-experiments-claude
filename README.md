# RSH-NPU · 第二版（分支 `v2`）

华为昇腾 910B2 上的 SpMM 研究，场景是 GNN。本分支是 2026-11-16 重新设计后的**第二版**，和第一版分开存放。

## 第一版在哪

| 位置 | 内容 |
|---|---|
| 标签 `v1-final`（= 原 `main` 的 `df65390`，包三十一） | 第一版的完整快照，冻结不改 |
| 分支 `main` | 第一版原分支，保留不删；第二版不再往里提交 |

要同时看两版，用工作树把第一版检出到旁边的目录：

```bash
git worktree add ../rsh-npu-v1 v1-final
```

第一版里没搬过来的东西（实验数据、参考实现与脚本、旧讨论记录、`github-20261030-new-rsh2NPU/` 原始代码等），都在这个工作树里。逐项索引见 `架构与代办/第一版资料索引.md`。

## 从哪读起

1. `CLAUDE.md`：项目背景（第二版）。
2. `架构与代办/架构与代办-第二版.md`：分层架构，以及每层的代办。**全局进度只看这一份。**
3. `架构与代办/拍板记录-第二版.md`：第二版的全部拍板。
4. `架构与代办/新接手AI工作单.md`：新接手的 AI 先读这份。
