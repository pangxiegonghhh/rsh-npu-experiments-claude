## 判断树（主线分叉，依赖 G1、G2 实测）

```text
G1：相同 AIC nnz 占比下，流水线 B 的 padding / T 是否明显少于 NeutronSparse？
 ├─ 否 → 上下文感知划分空间有限，重新找切入点（G2 不用看）
 └─ 是 → G2：B 的段数 R 对供数耗时影响大吗（已计入双缓冲重叠）？
          ├─ 是 → 主线：B 供数代价驱动的划分 + 布局协同设计
          └─ 否 → 主线：上下文感知划分；ND2NZ 只作工程优化
```

G2 判据的幅度基准：合成矩阵上列置换把段数 R 降 18%–26%（不是平均段长看上去的 4.9 倍），
应问「R 降两成能换来多少 AIC 时间」，并扣除 NeutronSparse §6.2.1 的 L2 预置已拿走的部分。
出处：`讨论记录/2026-11-03-路线评审/03-ND2NZ收益与B供数代价.md`。
