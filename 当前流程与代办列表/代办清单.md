## 已确认、无需再排期的项

这些在讨论中已经定论，不再作为待办，仅记录结论供查：

- 公平性问题已被 `candidates.md` §2 的统一接口中和，不需为公平性砍候选（出处：`04`）。
- 连续列段升为正式指标和变量，不再只是观察项（出处：`04` 分歧三）。
- 细粒度行划分同时得到窗口集合和残余集合，原大纲已如此，不需合并（出处：`06`）。
- 列置换不是创新点，它服务的目标才是；NeutronSparse 全局阶段已做列置换（为 tile 密度），
  本项目要的列置换是为了压低段数 R（出处：`08` §7 讨论中确认）。
- 第一层是全局重排，不是「RSH 行重排」；候选搜索从目的（压低 U_w、R_w）出发，不局限于
  RSH 式重排，跨层、不忠于 RSH 原算法均不构成毛病（出处：`08` §7）。
- **Cora 先导结果已归档**（2026-11-04），落在 `第一层实验结果/cora-pilot-20261104/`，
  程序与配置哈希经核对与封存归档一致，8 个方法视图 `correct` 全为 True。这是第一层第一份
  可引用的真实矩阵结果；此前记录中「Cora 未归档、第一层除合成矩阵外无可引用真实结果」的
  说法**自此失效**。限定：单张矩阵、`weighted_alpha=0.0`（属 T4）。
- **第一层研究骨架已建立**（2026-11-04）：前提假设 → 研究问题 RQ1–RQ4 → 方法空间（按阶段 A–E 拆分）→
  评价协议 → 实验与归因 → 选择与交付，见骨架。
- **场景取 GNN 类工作负载**（A 固定且反复调用，B 由流水线生产）；motivation 须写明场景，不得泛称一般
  SpMM（出处：骨架 P1）。
- **主视图为对称置换**；独立列置换只作参照上界。R_w 的收益只在 B 物理上按新顺序存放时兑现，对称置换在
  GNN 中满足此条件（出处：骨架 P2、P3）。
- **ρ 不作排名指标**：同一矩阵 NNZ 固定时它只是 1/T 的换算（出处：骨架 §3.1）。
- **第一层输出短名单（2–3 个组合），不选唯一胜者**，交第二层在真实划分规则下复选（出处：骨架 §5、P6）。
- **P10：对称视图下残余行仍作为列存在**，其编号位置影响其他窗口的 R；第一层划分后的 R 按"原位""末尾"
  两种放置规则分别报告，放置规则作为 E 阶段可调部件（出处：`2026-11-05-0334-残余点编号与Ascend-SpMM对motivation的影响`、骨架 P10）。
- **motivation 补充 Ascend-SpMM**：它已按窗口列并集计 AIC 代价、按窗口密度整窗分配，但窗口成员固定于输入
  行序、整窗进出；创新点 1 收窄为行粒度增量判据 + 窗口成员可变，创新点 2 的新增部分限于段数 R_w；G1 拆为
  G1a、G1b（出处：`2026-11-05-0334-残余点编号与Ascend-SpMM对motivation的影响`；权威措辞见 `流程图.md`）。
- **RQ1 补充调研结论**：C1、C2、C7 保留；C3/C4/C7 增"换输入编号"变体（第一轮单部图 Rabbit 粗排）；C5 保留
  二部图版并增 C5-U，局部阶段可换共同邻居链接；C6 升主（带时间上限）；新增 C8-METIS、C9-Gorder 与 C9-S；新增前提
  P11（出处：`2026-11-05-0408-RQ1补充调研讨论结论`）。
- **RQ2（空白一）调研结论**：对称视图下 ΣR = 非零 W×W 块数 Γ + 块内多余段 − 交界合并；廉价排序基线 = D-greedy（亦为默认 D 阶段）；
  新增 C6-M、C10-BP、P-LS(λ)、B-RCM-ref；评价增报 Γ、R − Γ 与两套 R；新增前提 P12（对角口径两套并列）；创新点 2 不收窄，三类形式先例在相关工作中引用；
  需要新实验数据时由规划方出方案、其他 agent 执行（出处：`2026-11-05-1430-RQ2空白一调研结论`）。
- **置换不引入原子冲突**：置换只改编号，原子冲突只在同一行的非零被分给两种核时出现；第一层的行、列、对称
