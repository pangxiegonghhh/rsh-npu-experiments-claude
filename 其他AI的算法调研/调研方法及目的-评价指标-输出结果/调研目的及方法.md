# 调研目的及方法

**以改善 NPU row window 的局部稀疏结构为目标，独立开展广泛、深入的文献调研，再把合适的已有算法融入我们的研究流程。**

1. **目标决定算法选择。**

   行重排要帮助后续类 RS-tile 构建，让同一窗口内的非零列更多重叠、列并集更小，进而提高列压缩后的稠密度、减少逻辑 Tile 和冗余计算。RSH 是研究起点，具体重排算法可以根据这个目标选择、替换或组合。

2. **独立建立检索范围。**

   主动寻找 SpMM、稀疏矩阵重排、行聚类、块稠密化、面向矩阵计算单元的分块等相关研究，并沿引用和后续工作继续扩展。用户提到的 iterative clustering、UBT、可变宽度相似性计算、Blocksmith，只是未经详细了解的补充线索，需要查证其内容与相关性，不能让这几个名称限定整个调研范围。

3. **借鉴要深入到算法如何被整合。**

   按用户举的例子，Neutron 把 Rabbit 算法融合进自己的算法流程：已有算法可以承担系统中的一个具体阶段，再与作者自己的设计衔接。对我们而言，也应研究清楚候选算法解决什么子问题、输入输出是什么、怎样与后续细粒度划分和窗口构建连接，以及哪些部分需要适配 NPU。最终形成的方法可以建立在已有算法之上，同时清楚交代来源、组合方式和自身改动。

4. **调研要形成可验证的方法选择依据。**

   需要理解各方法的相似性定义、聚类或排序机制、优化目标、适用矩阵和预处理成本，再在统一条件下评价它们对窗口列并集、压缩后稠密度、逻辑 Tile 数量的影响。也要分清改善来自行序、聚类分组还是列重排，随后通过对应层次的实验验证。

后续深度调研的交付应包括：相关方法的系统梳理、机制与取舍比较，以及它们如何接入本项目的明确依据。
