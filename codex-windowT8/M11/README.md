## 设备与时序

M11正式20区组全部来自同次开机的物理NPU1（PCI0000:01:00.0）；M11b是重启后在物理NPU5（0000:41:00.0）完成的独立补测，20区组不与M11合并。复用实例OP08JZ85MYKCJKH3，未同时用两张卡测同一任务，未修改M8目录。两次结束均已核对平台关机；M11约90分钟/估算6元，M11b约30分钟/估算2元，以账单为准。

M11计时前1104项正确性、计时后594项强地址复核均通过；M11b普通84项及强地址84项全部在其计时之前通过。B3直接消费门transpose50/50正确、plain-only50/50不等价，未强行进入差价计时。B1按计划确认已随机而取消设备重测。

## 下载后离线复核

不需要开机、不运行回传binary。Python 3.10+，另需NumPy、SciPy、Matplotlib。已有环境可直接执行：

```sh
cd codex-windowT8/M11
python3 verify_results.py
```

脚本先验全部发布文件SHA，在临时副本恢复两个证据包，再重算M11的45,920条原时钟、R1–R12、原M11统计及M11b的1,680条统计，结束清理临时副本；原报告/数据不覆盖。

只想解包查看原始CSV/每核stats：

```sh
python3 restore_evidence.py
```

两份`published-evidence.tar.gz`是明确选择范围的便携证据包，**不是**本机完整取证镜像。完整镜像518,508,328字节和72,655,915字节的原始SHA、公开证据SHA/范围见[PUBLICATION-ARCHIVES.json](PUBLICATION-ARCHIVES.json)；完整镜像均已本地回收。Git包保留全部有效计时和输入，M11的R12所需54格回读、M11b全部前置门/B3回读；其他大型C回读只在完整镜像中。
