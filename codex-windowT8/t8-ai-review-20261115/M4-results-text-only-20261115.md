# T8 M4 实验结果（2026-11-15）

已完成 2,592 个合成用例的 20 轮主计时（51,840 个有效点样本），以及 Cora B0/B1 共 40 个回放用例的 20 轮计时（800 个有效点样本）。主 R 模型在 0/20 个精度、N、缓存组合中同时通过 B0/B1 回放门槛。

**本轮不能据主 R 模型判定 G2 成立或不成立。** 原因是合成模型未通过真实回放验收；这与“b 的区间含零且段数项占比低于 2%”所对应的无可测代价结论不同。

## 实际测到了什么

实卡为 Ascend 910B2 物理 NPU 1，CANN 9.0.0，24 个 AIC。主计时前六轮在暂停前完成，后十四轮在同一节点、同一物理 NPU 恢复后完成；重新通过 P0 计时/噪声与资源核查、24 个首轮和五轮计时试跑。未完成的旧轮次保留并排除。

K-D 使用固定稠密 A、小块 K=16，包含 B 供数、MTE1 和 MMAD。计时采用全局设备 makespan，再除以所有核处理的窗口/矩阵数；b 乘 24,000 换成每核等效 ns。这是并发吞吐口径的有效系数，不能解释成一条硬件搬运指令的独立延迟。

gmax 是当前内核两块 B1 缓冲容量允许的最大偶数，A 直接进入 A2；它不是吞吐最优配置，也不能直接用于另行预留 A1 的内核。

Cora 读取真实 B 行段表，24 个 AIC 在互不重叠的 B 副本上回放相同窗口顺序；尾块补零调用计入实际 API 数。它不是完整稀疏 A、单份输入的端到端 SpMM。

热/冷档固定请求的有效 B 行工作集为 32 MiB/至少 1 GiB。Cora 单份矩阵中的行会复用，单份有效 B 可以放进 L2；全局副本工作集大于 L2，并不意味着每次行访问都来自 HBM。没有流量 PMU，不能将模型误差归结为某个已证实的缓存机制。

## B0→B1 实测收益

Cora 的 U 从 9,583 降至 6,035，R 从 8,565 降至 2,927（约降 65.8%）；按合法合并、字段上限拆分及补零计算的 API 次数约降 49%～51%。B1 同时改变 U 和 R，实测总收益不能全部归因于段数。

- FP16 / hot：五档 N 的实测耗时降幅为 5.3%～46.1%。
- FP16 / cold：五档 N 的实测耗时降幅为 5.3%～47.0%。
- FP32 / hot：五档 N 的实测耗时降幅为 44.9%～46.2%。
- FP32 / cold：五档 N 的实测耗时降幅为 44.0%～46.9%。

本文实测降幅采用两组耗时均值之比；同一随机块中 B1/B0 比值的 20 轮均值及其区间属于另一统计口径，不与前者混用。

## P0 L2 曲线补验

历史进展文档曾记载一次 64 KiB～1 GiB、每侧 20 样本的缓存扫描；本轮没有逐项核对那批旧原始记录及拐点判定，因此不能声称此前从未扫描。下列是当前物理 NPU 1 上重新做的 30 样本独立复核，晚于 M4 正式计时及原始归档，不能写成事前完成的拐点验收。它既不改 M4 观测，也不事后排除格子。

补验使用已验收的 v4 连续搬运二进制，64 KiB～1 GiB 共 15 档，AIC/AIV 各测；每点丢 5 次、留 30 次，初始每次请求 32 GiB，CV 超过 2% 时增加四倍批量复测一次。带宽按请求字节计，包含显式 MTE2 完成栅栏与固定输出工作，不是 M1 共享判定或 α/β 标定。

描述性拐点法提前登记为两段对数带宽均值，至少各含两点；要求下降至少 20%、BIC 改善至少 10。C 取相邻测试大小的几何中心，只是变化位置估计，不是精确缓存容量。

## 复测与证据范围

按照预登记决策顺序，已通过模型回放但仍需增大批量一次的组合为 0 格。模型回放失败的格子不因增加重复次数而自动获得解释资格。

另有跨轮波动需要保留：Cora FP16/N16 的 B0/B1、两档工作集四点的 IQR/均值为 15.1%～15.2%；其余 36 点最多 3.4%。组内哨兵漂移通过不等于跨轮波动小，原因尚未查明。不能用稳定的 B1/B0 比值掩盖绝对耗时的波动，也不能把它直接归因为某种缓存或调频机制。

全卡正确性与计时检查分别保存；正确性阶段捕获全部窗口，计时阶段回读每核最后窗口并检查计数、保护区、元数据和输入完整性。独立 CPU 地址表审计另行重建 2,592 个合成用例的要求行序，并直接读取原始 CPU 准备的 Cora segtable.csv 核对 40 个回放用例。7,896 个输入二进制文件与实机运行文件的规范聚合 SHA256 一致。

M4 官方模型的八条核验路径用于 ND2NZ 指令原语证据；运行时计数是 API 调用数，不能称作实卡 PMU 指令退休计数。模型时钟没有用于性能。

M5 已单独完成，性能数据来自前一天的物理 NPU 4，不能与本次 NPU 1 的 M4 时延直接拼接。整个 T8 或全部 K0 尚未因此完成。

本报告依据正常 Jupyter 页面读取且 SHA256 校验一致的 JSON 摘要；原摘要数值保留九位有效数字，下列展示表另有舍入。权威全精度 JSON、逐轮 CSV 和逐文件哈希在原始证据包。本文足以阅读和讨论已报告结果，不能代替原始样本重做回归、置信区间或异常追踪。
