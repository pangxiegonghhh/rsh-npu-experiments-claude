## 校验已入库部分

`SHA256SUMS` 覆盖完整归档的全部 4999 个成员，因此直接 `-c` 会报 `inputs/`、`orders/`
两个前缀下的条目缺失。只校验已入库部分：

```bash
grep -v -E '^[0-9a-f]{64}  (inputs|orders)/' SHA256SUMS | shasum -a 256 -c
```

（Linux 上 `shasum -a 256` 可换成 `sha256sum`。）本文件不在 `SHA256SUMS` 覆盖范围内。
