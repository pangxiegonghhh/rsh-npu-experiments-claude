## 与合成矩阵那一轮的可比性

`manifest.json` 的 config 与封存归档内合成矩阵那一轮**逐项相同**：

```
w16=16, k16=16, rsh_k=8, weighted_alpha=0.0, seed=0,
neutron_cluster_windows=8, rsh_refine_passes=2,
methods=[original, rsh, rabbit, neutron], views=[row_only, native]
```

程序哈希也一致，故两轮差异可归因于矩阵本身，可直接并列比较。

## 限定（引用时必须一并标明）

- **单张矩阵的先导结果。** 首轮其余五张（wiki-RfA、dawson5、olafu、pattern1、human_gene1）
  与 T5 的 ogbn-arxiv 均未跑。
- **`weighted_alpha = 0.0`**，即普通 Jaccard，而 RSH 论文要求 α>0（`w_j = d_j^(−α)`）。
  故 `rsh` 行是启发式近似，**不是原论文算法的复现**，属 T4。
- 本次只核验与读数，**未重跑实验、未改动程序**。
- 与合成矩阵相比，两项关键幅度差近一倍（R 降幅、ρ），说明这些幅度**强烈依赖矩阵**，
  不宜由单张矩阵定常数。
