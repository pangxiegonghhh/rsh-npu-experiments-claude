## 1. C5-U：单部图 Rabbit 粗序 + anchor-Jaccard

**来源。** `candidates.md` §7（C5）；用户 2026-11-05 决定（`讨论记录/2026-11-05/2026-11-05-0408-RQ1补充调研讨论结论.md`）：二部图版 C5 保留，另设单部图版 C5-U，二者只差粗排用的图。
Rabbit Order 作者实现（Arai 等 IPDPS 2016；`github.com/araij/rabbit_order`）。

**完整流程。**

1. 以 A0 为无向图（n 个点、每条无向边一次）调用真正的 Rabbit Order，固定作者 ref（同 C5：`f93776e9…`），得到 old→new 编号；按新编号排序得粗序。
2. 其余与 C5 第 3–5 步相同：按粗序切成 Q = 8W 个非空点的粗范围；每个范围内取第一个未分配点为 anchor，按原始支持集 Jaccard 选 W−1 个最相似的点，平分时依粗序、再依原编号；
   形成组，展平，附空点。

**本项目适配。** 单部图上每个点只有一个编号，直接就是对称视图；图规模从 m + n 降到 n。Q = 8W 沿用 C5 的工程适配，不称 Rabbit 的社区边界。

**成本与失败条件。** Rabbit 近线性（作者实现多线程，线程数与运行间的不确定性须记录）；局部阶段 O(nQ) 次评分，交集另计。
**Rabbit 依赖 Boost、libnuma 与 tcmalloc，macOS 上可能无法编译【待核】**；不能编译时在 Linux（含容器）上运行，仍不能时记 INCOMPLETE，**不得用 BFS 近似顶替仍称 C5-U**（先导里的 rabbit 就是 BFS 近似）。

**待验证假设。** GNN 图 hub 多时，二部图版（把"用到同一批列的行"归为一类）比单部图版更利于 U；单部图版对 R 更直接（星形图例子见 RQ1 补充调研 §6）。

## 2. C5-CN、C5-U-CN：局部阶段换为共同邻居链

**来源。** Acc-SpMM（PPoPP 2025，arXiv 2501.09251）§3.2、算法 1：受模块度重排启发建树，再在树上做 DFS，每一步取"与当前点共同邻居最多"的未访问叶点作下一个点，
平分时按 DFS 序（原文例子）。原文未写没有任何共同邻居时如何处理，复杂度只给 O(n log n) 的表述，未报重排耗时【沿用 RQ1 补充调研 §3.2，2026-11-06 复核原文】。

**完整流程。**

1. 粗序与粗范围同 C5（二部图）或 C5-U（单部图）。
2. 每个粗范围内，以第一个未分配点为链首；反复从该范围的未分配点中取与**当前点**共同邻居数（A0 下两行支持集交的大小）最大者接到链尾，平分依粗序、再依原编号；
   若范围内没有点与当前点有共同邻居，取范围内粗序最靠前的未分配点。
3. 链按 W 切组，展平，附空点。

**本项目适配。** 只替换 C5 第 4 步的局部规则（anchor 固定、按 Jaccard 一次选满 W−1 个 → 逐点接链、看当前点），其余不动，构成单变量对比（骨架 §4.2 RQ1 第 2 条）。
原文窗口 8 行、度量为每个 Tensor Core 块的平均非零数，与本项目 W16、U/T 不同。

**成本与失败条件。** 每步扫描范围内未分配点，O(nQ) 次求交；用倒排表增量维护共同邻居数可降成本。

**待验证假设。** 共同邻居链相当于 w = 1 的 Gorder S_s，链上相邻点相似、远处渐变，划分后受成员平移影响应小于 anchor 版（对齐红利 A 小）。

## 3. C8-METIS：图边割划分

**来源。** Karypis & Kumar（SISC 1998）的 METIS；Merkel 等（PVLDB 2025）§4.1 报告 METIS 类重排在 GNN 训练中收益居前；用户 2026-11-05 决定新增为主候选，容量修复沿用 C6。

**完整流程。**

1. 以 A0 为无向图（无自环、无边权），去掉度为 0 的点，非空点数 n′，分区数 p = ⌈n′/W⌉。
2. 调用 METIS k-way 划分，目标为边割，不平衡容忍 1.03（`ufactor = 30`，与 C6 的 ε = 0.03 相同），种子 0；保存原始输出。
3. 容量修复与组编号**完全沿用 `candidates.md` §8 第 3–4 步**（目标大小前 p−1 组为 W、末组为余数；从超额组向不足组移动使总列并集增量最小的点）。
4. 组内按原编号排序，展平，附空点。

**本项目适配。** 修复规则用 U 而非边割，使 C6 与 C8 只差划分目标（connectivity 对边割），构成单变量对比。p 很大（ogbn-arxiv 约 1.06 万），须检查 METIS 在极多小分区下的质量与耗时。

**成本与失败条件。** METIS 多层划分近线性；修复为启发式。工具不能给出 p 个分区或超时时记 INCOMPLETE。macOS 可用 Homebrew 的 metis 与 pymetis【待核版本】。

**待验证假设。** 社区结构强的图上，边割小意味着同组点的邻居大多在组内，U 与 Γ 都低；星形图例子提示边割可能偏离 U（RQ1 补充调研 §6）。

## 4. C9-Gorder、C9-S、C9-β：滑动窗口贪心

**来源。** Wei 等（SIGMOD 2016）§2 式 (1)–(3)、§3：最大化窗口内两两得分之和 F = Σ S(u, v)，S = S_s + S_n；S_s 为共同入邻居数，S_n 为互为邻居的次数；
窗口默认 5；按最大入度点起步；出度大于 √n 的 hub 不参与更新。

**完整流程（与参考实现一致）。**

1. 起点：A0 度数最大的点（平分取原编号小者）。
2. 每放置一个点 u：对 u 的每个邻居 x（若 deg(x) > √n 则跳过 x），给 x 的每个邻居 v 的得分 +1（S_s）；对 u 的每个邻居 v 的得分 +2·β（S_n，对称图中 u→v、v→u 各记一次）。
   窗口长 w = W−1，最早放入的点离开窗口时做相同的减法。
3. 下一个点取未放置点中得分最大者，平分取原编号小者；若最大得分 ≤ 0，取未放置点中度数最大者（平分取原编号小者）。
4. 重复至全部放置。

C9-Gorder：β = 1；C9-S：β = 0；C9-β：β ∈ {0.5, 2, 4}（T21 的 J3 扫描）。

**本项目适配。** w 由原文的 5 改为 W−1 = 15；对称图的 S_n 记 2；起步与回退规则为参考实现的确定性约定。

**成本与失败条件。** 原文用"unit heap"使每步取最大与增减得分均为 O(1)，总代价 O(Σ_u d(u)²)；参考实现每步对全部点求 argmax（O(n²)），只适合 Cora，
大图须按原文 unit heap（或按得分分桶）实现，并在 Cora 上与参考实现逐位比对。

**待验证假设。** S_n 降 Γ、R 而几乎不动 T（Cora：C9 对 C9-S，Γ −16%，T +0.7%，空白一 §3.2）；β 增大时 Γ 单调降、T 先平后升（T21 H4）。

## 5. C3/C4/C7 的换输入编号变体（-R）

**来源。** 用户 2026-11-05 决定（RQ1 补充调研 §6）：同一算法、换输入编号，即先对矩阵做一次对称粗排，再原样运行 C3/C4/C7；第一轮粗排用单部图 Rabbit；
若 C5 对比显示二部图明显更好，第二轮换二部图。

**完整流程。**

1. 用 C5-U 第 1 步得到粗序 π₀，构造对称置换后的矩阵 A′ = P A Pᵀ（行号、列号都换成新编号）。
2. 在 A′ 上原样运行 `candidates.md` 的 C3-W4、C3-A、C4-U、C4-T、C7-I（各自的分桶 ⌊j/b⌋、"按最小非零列号排序"的候选池、处理顺序都基于新编号），算法本身一字不改。
3. 把输出的行序映射回原编号，作为该变体的 `row_perm`。

**本项目适配。** 粗排耗时计入变体成本。C3-W1 不做 -R（b = 1 不依赖列号相邻，但其处理顺序仍依赖编号；第一轮不纳入，必要时再补）。

**成本与失败条件。** 粗排一次可被五个变体共用，但每个变体的成本表都要计入一次粗排时间（另列共用部分）。Rabbit 不可用时 -R 变体一并记 INCOMPLETE。

**待验证假设。** 收益随 B0 的 ΣR/ΣU 增大（原始编号越无局部性，换编号越有用，P11）；GNN 图上 C3-W4 原版不如 C3-W1，换编号后追平或反超；带状有限元矩阵上收益小（RQ1 推断 (b)）。

## 6. C10-BP：递归二分到 W 点

**来源。** Dhulipala 等（KDD 2016，arXiv 1602.08820）§3–§4：以"每个点的邻居编号 log-gap"为目标的递归图二分，每层若干轮按收益成对交换；空白一 §2 与用户 2026-11-05 决定新增。

**完整流程（与参考实现一致）。**

1. 数据点 = 全部非空点；查询 = 每个点的邻居表（对称 A 下即行）。
2. 对当前点集 V（|V| = s > W）：左侧大小取 s₁ = W·⌈s/(2W)⌉、右侧 s₂ = s − s₁；以种子 0 的随机序初始划分。
3. 每轮：对每个查询 q 统计其在左右两侧的邻居数 d₁、d₂；代价 Σ_q [d₁·log₂(s₁/(d₁+1)) + d₂·log₂(s₂/(d₂+1))]；算出每个点移到另一侧的收益；两侧各按收益降序配对，
   收益之和为正则交换，否则停；本轮无交换即停；每层至多 20 轮。
4. 对两侧递归，直到 |V| ≤ W；叶子即组（大小为 W，末组除外），叶内顺序交给 D 阶段。

**本项目适配。** 原文递归到几十个点为止、叶内顺序未说明；这里递归到 W 点、左侧取 W 的倍数，使叶子与窗口对齐。

**成本与失败条件。** O(m log n + n log² n)；参考实现为纯 Python，大图须移植（T21 已列）。

**待验证假设。** Cora 上 BP 是压 U 的成组方法（U 36.08，与 rsh 相当），对 R 无额外优势；它依赖精确对齐（对齐红利 +37.9），划分后须在残余集合确定后重做（空白二 §2.1）。

## 7. C6-RB 与 C6-M：递归二分超图划分与加消息网版

**来源。** C6-HP 见 `candidates.md` §8；消息网见 Selvitopi、Acer & Aykanat（IEEE TPDS 28(2), 2017）Algorithm 1：在递归二分的每一步，为当前部分与每个其他部分加 send / receive 消息网，
消息网代价 t_s（相对通信量网的 t_w），割尺寸与消息数相关；用户 2026-11-05 决定新增 C6-M。

**完整流程。**

1. column-net 超图：顶点 = 非空点（单位权重），网 = 列（单位代价），管脚 = 在该列有非零的行（A0）。
2. **C6-RB**：用超图划分器做递归二分，每步把目标大小设为 W 的倍数（左侧 W·⌈s/(2W)⌉），直到每部分 W 个点；ε = 0.03，种子 0。容量偏差用 `candidates.md` §8 第 4 步修复。
3. **C6-M**：与 C6-RB 完全相同，只在每个非根二分步，为当前部分 V_k 与每个其他部分 V_ℓ 加一张消息网，管脚 = V_k 中与 V_ℓ 有边相连的点（对称 A 下 send 与 receive 两张网管脚相同，合并为一张），
   代价 mnc ∈ {1, 4, 16}（通信量网代价 1；mnc = 0 即 C6-RB）。"其他部分"取递归树当前层已存在的全部部分【待核原文 Algorithm 1 的确切定义，实现以原文为准】。
4. 组内按原编号排序，展平，附空点。

**本项目适配。** C6-HP（直接 k 路划分）与 C6-RB（递归二分）可能结果不同；C6-M 的单变量对照是 **C6-RB**，C6-HP 另报。消息网对应非零 W×W 块数 Γ（空白一 §4.1 的对应关系）。

**成本与失败条件。** 分区极小（每部分 16 点）、部分数极多，消息网数量随部分对数增长，划分时间可能远超文献的 7%–48% 增幅；沿用 C6 的时间上限，超时记 INCOMPLETE。
需要能在两次二分之间修改超图的划分器（PaToH 或 KaHyPar 的库接口）【待核在执行环境中的可用性】。

**待验证假设。** C6-M 比 C6-RB 降 Γ 与 R、U 升不超过 5%（T21 H6）；降幅小于文献的 52%（只压 U 的成组已顺带压低 Γ）。

## 8. B-RCM-ref：参照序

**来源。** Cuthill–McKee 反序；空白一 §3.1；用户 2026-11-05 决定只在 SuiteSparse 带状矩阵上作参照。

**完整流程（确定性，与参考实现一致）。** 各连通分量从（度数, 编号）最小的未访问点起步做 BFS，邻居按（度数, 编号）递增访问；全部分量依次拼接后整体反转。**不用 SciPy 的 `reverse_cuthill_mckee`**（平局处理随版本 / 平台变化，包九）。

**定位。** 参照序，不参与短名单；dawson5、olafu 上报，其余矩阵可报作参考。

## 9. D 阶段：D-greedy 与 D-exact

**来源。** 空白一 §5；用户 2026-11-05 决定 D-greedy 为廉价排序基线兼所有候选的默认 D 阶段。

**完整流程。**

1. **组内（D-greedy）**：每个窗口内，对窗口内点两两算 co(u, v)（同时用到列 u、v 的窗口数），按 co 从大到小连边（度 ≤ 2、不成环、co = 0 不连），得若干链，按链首在窗口内的位置依次拼接。
2. **组内（D-exact）**：Held–Karp 求 co 的最大权 Hamilton 路（端点自由），W ≤ 16 时可用，只在小矩阵上作参照。
3. **组间**：以各组首尾两点为端口，按端口对的 co 从大到小连接（每端口至多一条、不成环、允许整组翻转）；**不满 W 的末组固定在最后**。
4. 划分后：只对 AIC 窗口做；残余点的位置由放置规则决定（§10.2）。

**不变量。** D 阶段前后每个窗口的点集不变，ΣU、ΣΓ 必须完全相等，否则不得报数。

## 10. E 阶段（残余集合确定之后的后处理，骨架 P13）

### 10.1 P-LS(λ)：划分感知的成员局部搜索

**来源。** 空白一 §4.5（命名 P-LS）；空白二 §2.2；T21 的 J1。

**完整流程。**

1. 残余集合 D 确定后，取剩余点按当前序每 W 个切成窗口；残余点按当前序暂接在末尾（用于计 Γ 的块编号）。
2. 目标 ΣU + λ·ΣΓ，λ ∈ {0, 1}（T21 另扫 0.5、2）；ΣΓ 按"剩余点在前、残余点在后"的布局以 ⌊位置/W⌋ 计块。
3. 每轮把剩余点打乱（种子 0）；对每个点 u，取与它列重叠最多的 3 个其他窗口，逐一尝试与其中每个点互换，接受第一个使目标下降的互换；不满 W 的末窗参与互换但位置不动。
4. 某轮没有接受任何互换，或满 10 轮，停止。增量维护的 ΣU、ΣΓ 须在结束时与全量重算一致。
5. 之后接 D-greedy 与放置规则。

**成本与失败条件。** Cora 每次 20–55 秒（纯 Python）；大图须移植或给时限，超时报已完成轮数下的结果并记 INCOMPLETE。

**待验证假设。** P-LS(0) 抹平起点差别（Cora：8 个起点 284–301）；λ = 1 比 λ = 0 在末尾-co 下降 R 5%–15%、T 变化 ±3% 内（T22 R3-H5）；优于 NeutronSparse 式删后重排（R3-H9）。

### 10.2 残余点放置规则

**来源。** 骨架 P10（2026-11-06 修订）；空白二 §3。全部只改编号，不改 AIC 窗口成员、U、T。

| 规则 | 定义 | 地位 |
|---|---|---|
| **末尾-co** | AIC 部分（D-greedy 后）在前；残余点接在最后，按 co 贪心链排序：co(x, y) = 同时用到列 x、y 的 AIC 窗口数，从大到小连边（每点度 ≤ 2、不成环、co = 0 不连），链按链首在残余点原相对顺序中的位置依次排，未连上的点按原相对顺序插入 | **主口径** |
| 末尾 | 残余点按 π 中的相对顺序接在最后 | 参照 |
| 间隙 | 残余点作为单点簇与 AIC 组一起参与组间贪心（单点有两个端口，可夹在两个 AIC 组之间），未连上的接在最后；AIC 组仍各自连续 | 读侧下界参照 |
| 原位 | 残余点留在 π 中的位置，AIC 点按其序填入其余位置；不做 D 阶段 | 参照（与已有表 B 衔接） |
| 就近 | 每个残余点接在"π 中它前面最近的 AIC 点"所在窗口之后 | 诊断 |

**不变量。** 每种规则下 σ 是排列、AIC 窗口点集不变；末尾、末尾-co、间隙、就近四种规则下 AIC 写回段数等于窗口数。

## 11. 诊断指标

| 指标 | 定义 | 用途 |
|---|---|---|
| Γ | 窗口 w 的列在最终编号下落入的不同 ⌊位置/W⌋ 个数之和；全行与末尾类放置下即非零 W×W 块数 | 成员对 R 的贡献（空白一 §1.6） |
| R − Γ | 每窗 R 与 Γ 之差 | 排序（D 阶段）剩余的部分 |
| 对齐红利 A | T_full^φ − T_full，T_full^φ 为全行切口平移 s = 1…W−1 行（首窗只含 s 行）后 T 的平均；大图可只取 s ∈ {2, 4, …, 14} 并注明 | 是否依赖精确对齐（成员平移的度量，骨架 §4.2） |
| 写回段数 | AIC：各窗口 W 个输出行在最终编号中的连续段数之和；残余：残余点在最终编号中的连续段数 | 放置规则的写侧代价（不进代价模型） |
| ΣU_keep − ΣU_inplace | 划分后重新切窗与"删行不前移"的 ΣU 之差 | 为正即"切散"的签名 |
