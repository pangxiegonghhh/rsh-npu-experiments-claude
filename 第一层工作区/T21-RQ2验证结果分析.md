## 2. H1：D 阶段后 R 与 Γ 的差

判据：全行、D-exact（无则 D-greedy）后 meanR − meanΓ ≤ 1.5，各矩阵、各成员（含参数变体）。

| 矩阵（A0） | 用例 | 通过 | meanR − meanΓ（最小 / 中位 / 最大） |
|---|---|---|---|
| cora | 28 | 16 | −0.12 / 1.39 / 4.81 |
| dawson5 | 16 | 15 | −3.12 / −0.24 / 2.32 |
| olafu | 16 | 16 | −7.03 / −5.51 / 0.34 |
| pattern1 | 12 | 10 | −161.5 / −32.9 / 510.4 |
| ogbn-arxiv | 28 | 1 | −1.41 / 13.80 / 25.18 |
| wiki-RfA | 16 | 0 | 33.8 / 42.2 / 76.6 |
| human_gene1 | 16 | 0 | 141.9 / 210.6 / 976.6 |

A1 与 A0 几乎相同；两口径合计 117 / 264。

**判定：不成立。** 差值偏离有两个方向：

1. **高度数图上 R 远大于 Γ**（ogbn-arxiv、wiki-RfA、human_gene1）：一个列块被很多窗口共用（全行下 meanΓ 即每个列块平均被几个窗口用到，主集合中位数：
   cora 16、ogbn-arxiv 63、wiki-RfA 79、human_gene1 503），各窗口用的是块内不同的子集，组内一种顺序不可能让所有窗口都连成一段，
   块内多余段大量出现【推：机制；数字为实测】。
2. **带状 / 长行矩阵上 R 小于 Γ**（olafu、pattern1）：窗口成片用到相邻的整块，跨块交界合并，段数少于块数。pattern1 按单边判据「通过」10 例，
   但差值为 −161 至 −31，并不是「R ≈ Γ」。

cora 上（A0）不通过的 12 例恰好都是**专门压 Γ 的成员**（C6-M 三种、λ > 0 的全行局部搜索 9 种中的 8 种、SlashBurn）：Γ 压得越低，每块里装的列越多，块内碎片越多【推】。
这一点在 H5 也能看到：λ = 1 对 λ = 0，Γ 的降幅只有一部分变成 R 的降幅（中位数：cora Γ −19% / R −8%，ogbn-arxiv −9% / −3%，
wiki-RfA −8% / −3%；dawson5、pattern1 上二者相当），图上约四成。

**含义（方案 §9 原话）：** 块内碎片或交界不可忽略，D 阶段的重要性上升。分解式 ΣR = ΣΓ + 块内多余段 − 交界合并仍是恒等式，
「Γ 归成员、R − Γ 归排序」的记账方式不变，但「R − Γ 很小、R 主要由成员决定」只在 cora 与有限元矩阵上成立。

判据：(indep-CBM 的 R) / (对称 D-greedy 的 R) 随 W 增大而下降。范围：全行；cora、dawson5、wiki-RfA（ogbn-arxiv 的 indep-CBM 超对数预算未做）；
成员 B0、rsh-α0、C9-Gorder、C10-BP。

|---|---|---|---|
| A0，W = 16 → 128 | 0.58–0.73 → 0.48–0.58，4 / 4 单调降 | 0.47–0.62 → 0.43–0.59，3 / 4（B0 除外） | 0.66–0.86 → 0.71–0.77，3 / 4（B0 除外） |
| A1，W = 16 → 128 | 0.81–1.15 → 1.02–1.39，0 / 4 | 2 / 4 | 0 / 4（W = 128 时 3 / 4 > 1） |

**判定：A0 下成立（10 / 12），A1 下不成立（2 / 12）。** A1 下 CBM 贪心（全局 greedy-edge）在 cora、wiki-RfA 的部分成员、部分 W 上比对称视图的 D-greedy 还差（比值 > 1）：

「对称约束的代价」只宜在 A0 下报。另：独立视图的廉价规则「首次出现顺序」除 B0 外在所有 W 上都不如对称 D-greedy（比值 1.1–5.1，随 W 增大而变差）。
