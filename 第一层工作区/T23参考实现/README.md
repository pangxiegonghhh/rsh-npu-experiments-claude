## 2. 共同约定与短组后处理 P（规划方补全）

1. **输入**：A0（对称展开、去对角，显式零值保留），S_r = adj[r]，列号为原编号。**行序一律在 A0 上计算**，A1 只用于评价（T20 §0）。
2. **空点**（度为 0）不参与搜索，最后按原编号附加。Cora 没有空点。
3. **P 的扫描顺序**（规格 §2 第 3 步只说「从剩余最小组开始扫描」）：对每个目标短组，把其余尚未并入的短组按（大小升序、最小原行号升序）依次检查，
   能整组并入（合计 ≤ W）就并入并继续扫描，目标满 W 即停；已被并入的组不再当目标；目标处理完若满 W 记为「新形成的完整组」，否则留作短组。
4. **P 的输出**：原完整组（生成顺序）→ 新完整组（按目标的处理顺序）→ 剩余短组（大小降序、最小原行号升序）；**每组组内按原行号升序**；再附空点。
5. **「生成顺序」**：C2 = 组达到 W 行的先后（合并过程中满员的次序）；C3 = 组的创建先后。
6. **切窗割裂数**（诊断）：P 之后跨越两个及以上 W 行评价窗口的组数。
7. **C3-W4-noP**（规格 §2 末的消融）：按创建顺序展平原组，组内同样按原行号升序，再附空点。

## 3. C2-LSH（规格 §4）

| 项 | 规格 | 本实现的补全 |
|---|---|---|
| MinHash | 128 维、32 band × 4、种子 0，「具体 hash 算法随实现记录」 | h_k(x) = (a_k·(x+1) + b_k) mod (2⁶¹−1)；a_k、b_k 取 SHA-256(`C2-LSH|seed=0|k=<k>|a` / `…|b`) 前 8 字节，分别模 (2⁶¹−2) 加 1、模 2⁶¹−1。不依赖任何库的随机数，跨平台一致 |
| band | 共享任一完整 band | 第 j 个 band = 签名第 4j…4j+3 项；同一 band 编号且 4 项全同即为候选对 |
| 候选下限 | Jaccard 起始建议 0.2 | **J ≥ 0.2（含等号）**，用原始支持集精确计算 |
| 排序 | J 降序、两个原行号升序 | 用精确分数比较（不用浮点） |
| 合并 | 严格容量 ≤ W | 并查集按大小合并（大小相同时编号大的作根，只影响内部记账） |

Cora：LSH 候选 2892 对，J ≥ 0.2 的 2735 对；合并 1146 次，因容量拒绝 747 次；P 前完整组 19 个、短组 1543 个，P 合并 1390 次。

## 4. C3-W1 / C3-W4 / C3-A（规格 §5）

- 签名 F_b(r) = {⌊j/b⌋ : j ∈ S_r}；与组代表签名的 Jaccard ≥ 0.2（即距离 ≤ 0.8，沿用作者代码口径，规格已注明）就加入，用整数判断 5·|∩| ≥ |∪|。
- 每处理一行前，活跃组（未满 W）按（大小降序、代表原行号升序）重排，加入**第一个**满足条件的组；都不满足就以该行为代表新建组。代表固定为组的第一行。
- **C3-A**：b 按完整矩阵形状 D = max(m, n) 取 4 / 32 / 128（D < 50000 / < 100000 / 其余）。Cora D = 2708，b = 4，**与 C3-W4 行序相同**（SHA-256 一致）；
  按规格，这种情况复用 C3-W4 的结果，不计为独立证据。

## 5. C4-U / C4-T / C7-I（规格 §6、§11）

- 非空行按（最小非零列号升序、原行号升序）排成序列；每组开始时取序列中最前面的 L = 128 个未分配行作为本组固定候选池（含种子）。
- 每步对池中未分配行算：z′ = z + |S_r|，U′ = |U_set ∪ S_r|。C4-U 取 z′/U′ 最大；C4-T 取 z′/(W·K₀·⌈U′/K₀⌉) 最大（W = K₀ = 16）；
  C7-I 取 |S_r ∩ U_set| 最大。分数一律精确比较；平分时取行长 |S_r| 大者，再取原行号小者。
- 组满 W 或池耗尽（只在输入末尾发生）即结束本组；组内顺序 = 选入顺序；各组按生成顺序展平，再附空点。

## 7. 给移植者的提示

- 大图上 C2 的桶可能很大（候选对接近 m²），规格要求达到预先固定的内存 / 时间上限时记 INCOMPLETE，**不临时截断候选后沿用原名称**。
- C3 每行都要把活跃组重排一次，活跃组多时代价高；移植时可用等价的数据结构，但「按（大小降序、代表编号升序）取第一个满足的组」这一语义不能变。
- C4 / C7 的候选池是「本组开始时」的前 L 个未分配行，组内不补充；分数必须精确比较（交叉相乘），浮点会在平分处漂移。
- 移植版先在 Cora 上跑出与 §6 相同的 8 个 SHA-256，再上大图。
