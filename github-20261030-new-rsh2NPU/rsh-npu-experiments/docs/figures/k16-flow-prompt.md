# K16 供给流程图提示词

使用内置 imagegen 生成。示例固定为 16 行窗口、37 个不同列号、N_t=32。

画一张简体中文教学流程图，白底、扁平矩阵色块、清晰大字号、竖版约1024×1536。标题“37个离散列，怎样供给Cube？”副标题“已确定16行窗口；本轮特征宽度 Nₜ=32”。橙、蓝、绿三色分别代表三个块，灰色表示补零。分四个从上到下的步骤，用箭头连接，重点是矩阵形状与索引对应，不画芯片内部。

①“原始A窗口：16×1000”
画16行稀疏矩阵，文字“16行合起来，访问37个不同列号”。用两条示例映射突出“原A第2列 ↔ 原B第2行”“原A第701列 ↔ 原B第701行”。注明“原始列号可以很分散”。

②“把37个列号编号为局部0…36”
画两行对应表：上行“原列号：2，5，9，…，133 | 145，…，600 | 701，720，803，900，999”；下行“局部号：0，1，2，…，15 | 16，…，31 | 32，33，34，35，36”。三段分别16、16、5个索引，用橙蓝绿配色。省略号只表示省略显示。标注“col_map保存局部号到原列号的映射”。下方画局部A的16×37示意矩阵，稀疏深色格表示非零，其余留白。

③“按K16分成三块：16 + 16 + 5”
横向画三个等大的16×16正方形A块。第一橙色A₀，局部列0…15；第二蓝色A₁，局部列16…31；第三A₂，前5列绿色、后11列灰色，标“5列有效 + 11列补零”。括号标总形状16×48。说明“37补齐到48 = 3×16”。有效区域仍可有零，不能画成全部非零。补零列没有真实B行号。

④“同一映射读取B行，三个结果相加”
三条平行计算：
“A₀(16×16) × B₀(16×32) → D₀(16×32)”
“A₁(16×16) × B₁(16×32) → D₁(16×32)”
“A₂(16×16) × B₂(16×32) → D₂(16×32)”
B₀与B₁注明“各按col_map从原B读取16行”；B₂注明“读取5行，补11行零”。各B块都只取原B特征列0…31。第三B块画前5行绿色、后11行灰色。三个D用箭头汇入加号，得到“C窗口(16×32) = D₀ + D₁ + D₂”。三个D是同一输出窗口的部分和，绝不能画成拼接。
底部醒目一句：“A的列 ↔ B的行；三个K16块累加到同一个C窗口。”
底部三项短注：“W=16：A的行数”“K16：A每步16列 / B对应16行”“Nₜ=32：本轮32个特征”。数学与中文准确，布局清爽，少装饰，无水印。
