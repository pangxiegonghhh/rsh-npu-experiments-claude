文档状态：用户已审核，作为计划草稿归档。本文记录第一层实验的目标、已有程序及公开数据集实验补充；程序原型已经实现，完整多矩阵实验尚未完成。

实验背景：

- [RSH-NPU 主线与 ND2NZ 后续优化大纲（简版）](RSH-NPU主线与ND2NZ后续优化大纲-简版.md)
- [实验组织方式](实验组织方式.md)

## 1. 实验定位

本实验研究 RSH 行重排如何组织结构相似的行，输出可供下一层细粒度行划分使用的新行顺序和结构信息。

评价重点是结构变化。本层不接入 NPU Kernel，也不据此得出 Bitmap、RS-tile、Gather、ND2NZ、AIV/AIC 或 Cube 的性能结论。连续列段在本轮作为观察项，暂不加入 RSH 候选行特征。

## 2. 已有独立实现

核心文件：

- [rsh_reorder_experiment.py](rsh_reorder_experiment.py)：结构重排及统一评价程序。
- [test_rsh_reorder_experiment.py](test_rsh_reorder_experiment.py)：正确性与回归测试。
- [README-RSH-行重排结构实验.md](README-RSH-行重排结构实验.md)：程序使用说明。

已有实现包含：

- 原始行顺序、RSH 思路的简化实现、Rabbit 风格启发式和 Neutron 风格 Global–Local 启发式对照。
- `row_only` 与 `native` 两种视图。前者只使用行顺序并保留原始列编号，后者允许方法使用其列顺序。
- 支持集 Jaccard、倒排索引、kNN 图、MST/DFS 和局部 2-opt 等步骤。
- W16 行窗口与固定 K16=16 列分组的结构评价。
- 相邻行相似度、不相似度、窗口非零列并集、连续列段和 K16 数量等统计。
- 行排列双射、逆映射恢复、NNZ/值/原始列编号保持，以及 native 行列置换语义检查。
- JSON、CSV、SVG 输出。
- Matrix Market、JSON、CSV、CSR NPZ 输入，以及多个 `--input` 的批量运行入口。

以上描述的是当前原型的能力。Rabbit 风格实现主要是二部图遍历，Neutron 风格实现主要是粗顺序分组和组内相似行组织，不能将它们直接称为论文方法的忠实复现。正式方法对比前，需要进一步核对算法实现与论文的一致性。

## 3. 统一评价约定

同一批矩阵使用相同的全局参数、评价规则和行号 tie-break 规则，禁止按矩阵单独调参。第一轮 RSH 候选特征使用非零列支持集；`nz_r` 与 `Δ` 留到细粒度行划分层研究。

`W16` 在本轮指用于评价的 16 行分组，不改变 RSH 行重排算法，也不代替后续的 NPU 窗口设计。

当前程序中的 `k16_count = ceil(窗口非零列并集大小 / 16)`，表示将不同列紧凑组织后的 K16 分组数量这一结构代理指标；它不是按原始列号计算的物理块数量，也不是已经构建好的 RS-tile 数量。

主要比较采用 `row_only` 视图，`native` 作为行列同时重排的补充参考。记录相邻行与窗口结构变化、预处理时间、候选图规模，以及所有正确性检查结果。

## 5. 补充：使用公开数据集做实验

正式结构实验采用公开数据集中的矩阵，优先与 NeutronSparse 论文的数据集对齐。自行生成的合成矩阵继续用于调试与正确性检查。

NeutronSparse 论文的实验集列出 4 个 GNN 数据集和 16 个 SuiteSparse 矩阵。候选清单已经记录于 [neutron_dataset_manifest.csv](neutron_dataset_manifest.csv)，下载入口见 [download_neutron_dataset.py](download_neutron_dataset.py)。

此前讨论的第一轮候选为：

```text
cora
wiki-RfA
dawson5
olafu
pattern1
human_gene1
```

该列表是候选输入安排，尚不代表这六个矩阵全部完成下载、版本核验或实验。较大、较密矩阵需要结合预处理时间与内存开销逐步验证；具体批次可在数据获取和规模检查后确定。

每个公开矩阵应记录来源、文件校验值、原始维度、文件条目数和加载后的实际 NNZ；同时说明对称展开、重复坐标、显式零、自环或有向化等处理。若与论文表中的规模不同，应注明差异，不能仅凭同名就视为相同输入。SuiteSparse 也包含人为构造的基准图，因此“采用公开数据集”不等同于每张矩阵都来源于现实观测。

参考来源：[NeutronSparse 论文第 8.1 节及 Table 2](https://arxiv.org/html/2606.22482v1)。清单中的论文规模是待核验的参考值，下载文件本身才是实际输入的依据。
