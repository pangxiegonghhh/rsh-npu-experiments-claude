# 实验组织方式

文档状态：实验背景，已审核归档。

配套背景：[RSH-NPU 主线与 ND2NZ 后续优化大纲（简版）](RSH-NPU主线与ND2NZ后续优化大纲-简版.md)。

## 基本原则

RSH 迁移到 NPU 的实验应逐层推进。每一层先完成自己的设计，再进行针对性实验；后一层使用前一层已经固定的输出。这样才能判断收益或问题来自哪个层次。

整体层次关系为：

```text
RSH 行重排
        ↓
面向 NPU 的细粒度行划分
        ↓
NPU Row Window / 逻辑 Tile
        ↓
类 RS-tile 存储层
        ↓
A/B 数据准备
        ↓
L0A/L0B
        ↓
Cube
```

## 逐层实验安排

### 1. RSH 行重排实验

研究行重排本身如何组织结构相似的行，输出新的行顺序。

这一层先独立观察行顺序与局部结构的变化。评价用的固定行窗口，不等同于下一层设计的 NPU 窗口与残余行划分。

### 2. 细粒度行划分实验

在固定行顺序的基础上，设计窗口与残余行的划分规则。

### 3. NPU Row Window / 逻辑 Tile 实验

在固定窗口成员的基础上，确定 NPU 的窗口形状、逻辑 tile 组织和 `M、N、K` 映射。

### 4. 类 RS-tile 存储层实验

在固定窗口和逻辑 tile 的基础上，设计 Bitmap 等 A 存储格式及其描述信息。先以 Bitmap 作为主要格式进行验证。

### 5. A/B 数据准备实验

在前面结构和格式都固定后，先使用 B Gather，验证 AIV/AIC、GM ring、L0A/L0B 和 Cube 的供数路径。

### 6. 完整主流程实验

将前面各层连接起来，验证 RSH-NPU 主流程是否能够完整运行。

### 7. 后续 ND2NZ 优化实验

在主流程稳定后，再修改 RSH 行重排中的候选行特征，并比较 Gather 与 ND2NZ。

这里固定的是细粒度行划分的规则和参数；改变行顺序后，得到的窗口成员和列集合可能随之变化，需要重新记录与评价。

## 当前起点

当前先推进第一层“RSH 行重排实验”。后续各层在前一层输出固定后继续设计与验证。

第一层的实现与真实数据集实验补充见：[RSH 行重排结构实验计划草稿](RSH%20行重排结构实验计划草稿.md)。

本文只确定实验的组织层次和推进顺序，具体算法、阈值、窗口形状与存储字段留给对应层的设计。
