## 范围

- A 重排与细粒度行划分已完成；不以改变划分规则代替供给设计。
- FP16 A/B、FP32 累加是当前设计起点；K16 是基础分形组织粒度，不能未经核实称为唯一合法 Mmad K。
- 重点比较压缩/补零/分组存储及按列映射准备当前 B 的代价。
- 不把 GPU 的 warp 解码、原生稀疏 MMA 或更晚 NPU 型号能力套到 910B。
- 本阶段为研究和设计，可运行本地离线分析；设备编译、性能测试和新颖性证明分别说明证据状态。
