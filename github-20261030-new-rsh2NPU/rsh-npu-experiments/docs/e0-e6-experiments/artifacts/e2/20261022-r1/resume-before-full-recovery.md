## E2原启动步骤（历史；当前断点见顶部与E2总结）

1. 阅读研究报告§5.3和§7的E2定义、输入契约的跨核边界，以及E1总结/实际解码器。将编码语义基线与新的交接逻辑分开追溯。
2. 先实现Bitmap16/LocalIndex16的单缓冲、无重叠片上展开与共享L1消费，固定输出所有权；共同tiling导出共享地址，不能各核独立分配后假定地址一致。
3. 验证UB→L1实际路径、ready/release配对、资源预算与长循环逐次输出。覆盖q=1/2/4/8、奇数/末包、首包/末包、空闲AIV按同一同步协议参与，先关闭Residual。
4. 单缓冲正确后再做双缓冲；每个槽消费完才复用。与E1含GM中转的正确性对照保持相同A/B、列映射及FP64参考。
5. 本地先完成参数、地址、计数和输入检查，目标设备使用新构建目录，核验实际源码/产物哈希和SDK版本。若新租卡仍在付款页交给用户；已有实例恢复前确认状态。
6. 每次调用保存结果/关键中间量/debug/guard，检查数量和连续编号；完成后回收原始证据、本地重放、更新台账和本文件并关机。只做E2，不自动执行E3。
