**T24 系列的求解方式（判读稿 §1）：** 全矩阵汇总用**精确动态规划**，不用拉格朗日近似——`f[C] = 总列数 ≤ C 时的最小总非零数`，最优 makespan = `min_C max(α·C, β·f[C])`。初版用 μ 扫描有 1.0%–1.4% 间隙，会盖过 5% 判据，且在敏感性扫描上产生非单调的假结构。`t24_exact_menu.py` 另把每窗的移出子集从贪心改为枚举全部 2^16 个子集取帕累托前沿（贪心低估 0.05 个百分点）。`t24_synth.py`、`t24_driver.py` 里的合成幂律图只用于看趋势，**不替代真实矩阵**（方案 §6 第 4 步）。模型中 N 为公因子已约去，所有 makespan 数值都是「每 N」的相对量，不是绝对时间。

**注意事项：**

- 复算 T23 数据时必须按 `tau not in ('', 'none')` 取划分后行（`'none'` 表示全行），并按 `source != 'post-E'` 取后处理之前的行。审核会话曾因漏掉前一条而得到错误的 C4-U 有限元值 0.908（正确为 0.958），记录在 04 号 §1。
- `probe_*.py` 调用的是 Cora 先导的 **Python** 实现，不是 T23 实际使用的 C++ 移植版；两者在 cora 的 α=0、k=8 上一致，但不保证全参数范围一致（T4 方案 §5.3）。
- `probe_part.py` 的评价器是审核者自写的简化版：同一评价器下各参数档位的**相对**比较自洽，但绝对值与 T23 记录有约 1.8% 偏差，不得用来替代 T23 的数值。
